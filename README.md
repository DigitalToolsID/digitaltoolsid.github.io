# Digital Tools ID

Pusat Utilitas Digital untuk Estimasi Cepat & Kemudahan Sehari-hari (Kalkulator Finansial, Kesehatan, & Produktivitas).

---

## 📚 Indeks Dokumentasi & Rencana Pengembangan

Untuk melihat panduan arsitektur dan integrasi fitur yang sedang atau akan dikerjakan, silakan rujuk berkas-berkas berikut:

1. **[PANDUAN_SETUP_UMAMI_ANALYTICS.md](PANDUAN_SETUP_UMAMI_ANALYTICS.md)**  
   Panduan lengkap pemasangan analitik traffic pengguna secara real-time menggunakan Umami Cloud (menggantikan GA4 yang delay), langkah pendaftaran, dan instruksi teknis injeksi otomatis ke 40+ tools via `components.js`.

2. **[STRATEGI_DISTRIBUSI_URL.md](STRATEGI_DISTRIBUSI_URL.md)**  
   Dokumentasi strategi arsitektur URL per kategori (Keuangan, Kesehatan) agar link yang dibagikan ke komunitas spesifik tidak terdistraksi oleh topik lain.
